# 上线清单（AI赛事备忘录）

> **这份文件回答一个问题：备案批下来之后，怎么用最少的时间把网站开起来。**
> 路线：**A 静态上线** —— 服务器上只放"做好的网页"，不装 Node、不跑程序。
> （以后想改成"服务器自己每天采集"，不用推翻这套，见本文最后。）

---

## ★★★ 红线（写在最前面，别跳过）★★★

**备案没批下来之前：**
- 不许在服务器上开站；
- 不许把域名解析到服务器（解析了就是"用未备案域名提供访问"，会被驳回甚至处罚）；
- 服务器上可以先把网页传上去、先配好，但**不要开外网访问**（这一步其实也建议等备案下来一起做，免得自己搞混）。

这条是法律要求，也是你之前亲自定的规矩。下面的"彩排"部分**完全在你自己电脑上做**，不碰服务器。

---

## 零、今天就能做的彩排（不用等备案，2 分钟）

| 做啥 | 你会看到 |
|---|---|
| 双击 **`上线准备.bat`** | 重画网页 → 自检 → 打包。最后一行应该是 **⚠ 包本身是好的，但还不能开站：备案号还没下来** |
| 双击 **`预览上线效果.bat`** | 浏览器打开 `http://127.0.0.1:8001`，这就是"传上去之后观众看到的"（没有任何程序参与，只发文件） |

彩排时看到 ⚠ 是**正常且正确的**：包没问题，只是没备案号不能开站。
等备案号下来填进 `site-config.js`，再跑一次 `上线准备.bat`，结论就会变成 **✔ 可以上线**。

## 一、备案批下来的当天（按顺序做，约 15 分钟）

### 第 1 步：把备案号填进网页（1 分钟，在你电脑上）
- [ ] 用记事本打开项目根目录的 **`site-config.js`**
- [ ] 找到 `icp:` 那一行，把号码填进去。**注意末尾的 `-1` 一定要带上**，例如：
      ```js
      icp: '皖ICP备2026001234号-1',
      ```
      （填错格式的话程序**不会**挂上去，只在生成时打一行提醒 —— 宁可不挂，也不挂错号。）
- [ ] 存盘

### 第 2 步：一键准备好上传包（20 秒，在你电脑上）
- [ ] 双击 **`上线准备.bat`**
- [ ] 最后一行必须是 **✔ 可以上线**；不是的话，看上面的 ✘ 行先解决（都是它自己说清的问题）
- [ ] 记下它打印的：`deploy\dist\site-<日期时间>.zip`

> 想顺便取最新数据？**先**双击 `更新数据.bat`（约 40 秒），**再**双击 `上线准备.bat`。
> 两步故意分开：万一采集失败，你不会把旧数据当新数据传上去。

### 第 3 步：服务器上建站（宝塔面板，3 分钟）
- [ ] 登录腾讯云 → 打开**宝塔面板**
- [ ] 先确认系统版本：CentOS 7 **不用**重装（这条路不装 Node，用不到新零件）；
      这条是走 B 路线（服务器自己跑程序）才需要处理的老坑
- [ ] 宝塔 → **网站** → **添加站点**
      - 域名：`aicpt-memo.cn` 和 `www.aicpt-memo.cn` 都填上（以备案单上写的域名为准；**没备案的域名别解析**）
      - 根目录：记住它，一般是 `/www/wwwroot/aicpt-memo.cn`
      - 数据库、PHP：**都不要**（我们是纯静态）
- [ ] 宝塔 → **文件** → 进入网站根目录 → 删掉面板自带的 `index.html`、`404.html`（如果有）

### 第 4 步：把网页传上去（1 分钟）
- [ ] 宝塔 → **文件** → 网站根目录 → **上传** → 选 `deploy\dist\` 里那个 zip
- [ ] 上传完，右键这个 zip → **解压** → 解压到当前目录
- [ ] 解压后根目录里应该正好是这 5 样：**`index.html`**、**`detail\`** 文件夹、**`media\`** 文件夹、**`robots.txt`**、**`sitemap.xml`**
      （少了 `robots.txt` / `sitemap.xml` 的话，搜索引擎找不到你的站、收录会很慢 —— 自检里有一条专门盯这个；
        少了 `media\` 的话，网页会退回系统字体、背景变成一块纯色 —— 打开首页一眼就能看出来，自检里也有一条盯着）
- [ ] 解压完可以把 zip 删掉（**建议留着**：这就是你的"上一版"，万一要回退直接再解压一次）

> 包里只有"网页 + 网页要用的素材"，没有 `src\`、没有 `data\`、没有 `site-config.js` ——
> 备案号在生成网页时就已经写进 html 里了，所以传上去的东西就是观众能看到的全部内容，一个多余文件都没有。
> `media\` 里是 2026-09-17 换「深潜协议」风格时从用户的素材包里挑出来的东西：
> 3 个字体（`fonts\`）、1 张背景图（`bg\abyss.jpg`）、3 个图形（`mark\`），一共 7 个文件、约 430 KB。
> 打开 **`https://aicpt-memo.cn/robots.txt`** 应该能看到三行（User-agent / Allow / Sitemap）；
> 打开 **`https://aicpt-memo.cn/sitemap.xml`** 应该是一份列了 21 个地址的清单（1 首页 + 20 详情页）。
> 顺带：以后**换了域名**，记得改 `site-config.js` 里的 `siteUrl`，再跑一次 `上线准备.bat` 重传
> （不然 `robots.txt` / `sitemap.xml` / 分享链接里写的还是旧域名）。

### 第 5 步：解析域名（备案批了才能做，1 分钟 + 等生效）
- [ ] 腾讯云 → **域名解析（DNSPod）** → 给 `aicpt-memo.cn` 加一条 **A 记录**，指向服务器的**公网 IP**
- [ ] 再给 `www` 加一条（A 记录填同一个 IP，或 CNAME 到 `aicpt-memo.cn`）
- [ ] 等 10 分钟～几小时（本机可以先 `ping aicpt-memo.cn` 看解析到没有）

### 第 6 步：开防火墙端口（这一步最容易漏，漏了就是"网站打不开"）
腾讯云轻量服务器的防火墙是**两层的**，两层都要放通：
- [ ] 腾讯云控制台 → 轻量应用服务器 → **防火墙** → 添加规则：**80（http）、443（https）**
      （22 是远程管理、宝塔面板端口也要放通，不然面板打不开）
- [ ] 宝塔面板 → 安全 → 也确认 80、443 是放行的

### 第 7 步：申请 HTTPS 证书（30 秒）
> 注意顺序：**必须等域名解析生效之后**再申请 —— 证书要靠"域名指向这台机器"来验证。
- [ ] 宝塔 → 网站 → 你的站点 → **设置** → **SSL** → **Let's Encrypt** → 勾上 `www` → 申请
- [ ] 申请成功后，打开 **强制 HTTPS**
- [ ] 证书是 90 天一轮，宝塔会自动续；**别把自动续期的开关关掉**

### 第 8 步：验收（第 3 节那张表，一条条过）

## 二、以后每次更新网站（约 2 分钟）

- [ ] 1. 双击 **`更新数据.bat`**（约 40 秒，去三个官网取最新数据）
- [ ] 2. 双击 **`上线准备.bat`**（重画网页 + 自检 + 打包）
- [ ] 3. 宝塔 → 文件 → 上传新的 zip → 解压 → **覆盖**
- [ ] 4. 打开 `https://aicpt-memo.cn` 刷新，看顶部"数据采集时间"是不是刚更新的

> **想省掉第 3 步**：以后可以做成"双击一下就自动传上去"（用 scp/宝塔 API，需要服务器密码或密钥）。
> 现在先手动，是因为**知道你服务器在哪儿、用什么账号**之前，写自动上传脚本等于放一个没人验过的门。

**回退**：服务器上一直留着上一个 zip。出问题就把上一个 zip 重新解压覆盖一次，1 分钟回到上一版。
（数据不会丢 —— 数据在你电脑上，服务器上只有网页。）

## 三、上线当天要肉眼验收的 10 条

- [ ] 1. `https://aicpt-memo.cn` 打开**不报"不安全"**；输入 `http://` 会自动跳到 `https`
- [ ] 2. 首页顶部大数字 = 方块个数 = 能点开的详情页数（现在都是 21）
- [ ] 3. **电脑上一行 4 个方块，手机上一行 2 个**（这条一直只能靠真人看）
- [ ] 4. 随便点 3 个"详情"，内容齐全、点"← 返回首页"能回去
- [ ] 5. 详情页里"去官网报名"能跳到真官网（开新窗口）
- [ ] 6. 页面**底部有备案号**，点它能打开工信部网站
- [ ] 7. 在手机微信里把某一页链接发给"文件传输助手"，点开能正常看
      （发出去的那张卡片应该带**标题 + 一句摘要 + 小图标**，不是一条光秃秃的链接）
- [ ] 8. 故意打一个不存在的详情页地址（如 `/detail/tianchi-999999.html`），应显示"这个详情页不存在"，**不是白页、也不是别人家的页面**
- [ ] 9. **浏览器标签页上有一个"AI"小图标**（不是默认的空白文件图标）
      —— 这个小图标是直接写在网页里的（不依赖任何图片文件），所以只要网页能开，它就该在
- [ ] 10. 浏览器里打开 `https://aicpt-memo.cn/robots.txt` 和 `https://aicpt-memo.cn/sitemap.xml`，
      两个都能打开、不是 404（一个是三行字，一个是 22 个地址的清单）

## 四、出问题怎么办

| 现象 | 原因 / 办法 |
|---|---|
| 网站打不开（转圈超时） | 八成是防火墙：腾讯云控制台的 80/443 没放通，或宝塔安全里没放行 |
| 打开是宝塔默认页 | zip 解压的位置不对：`index.html` 必须**直接躺在网站根目录**下 |
| 点详情 404 | 解压时漏了 `detail` 文件夹（或者上传的不是新包） |
| `/robots.txt` 或 `/sitemap.xml` 打开是 404 | 上传的 zip 是**旧包**（2026-09-16 之前的包里没有这两个文件）。重新双击 `上线准备.bat` 打一个包再传 |
| sitemap.xml 里的网址不对 | `site-config.js` 的 `siteUrl` 填错了，或者换域名后没重新生成。改好再跑一次 `上线准备.bat` |
| 分享到微信只有一条光秃秃的链接、没有摘要 | 上传的 zip 是旧包（新包里每张页面都带了分享信息）。重新打一个包再传 |
| 页面还是旧的 | 浏览器缓存：`Ctrl + F5` 强制刷新；再确认解压的是不是最新的 zip |
| 底部没有备案号 | `site-config.js` 填完之后**没有重新生成网页**：双击一次 `上线准备.bat` 再传 |
| 底部没显示备案号、但生成时提示格式不对 | 号码写错了（多半是漏了末尾的 `-1`）。改对再跑一次 |
| 证书申请失败 | 域名没解析生效。等一会儿，`ping` 通了再申请 |
| 想退回上一版 | 上传上一个 zip 解压覆盖 |
| 自检报了 ✘ | 自检的每条都在说大白话，照着解决；实在看不懂就把那一屏截图发给 AI |

## 六、这套东西里每个文件是干嘛的

| 文件 | 作用 |
|---|---|
| `上线准备.bat` | **双击**：重画网页 → 自检 → 打包。上线前和每次更新前都跑它 |
| `预览上线效果.bat` | **双击**：在本地用"纯静态"方式开一次站（8001 端口），看传上去会是什么样 |
| `deploy\prepare.js` | 上面那个 .bat 真正干活的程序（三步串起来） |
| `deploy\preflight.js` | 自检规则：数据、页数、三个数字是否一致、脏字符、死链、孤儿页、外链协议、**robots/sitemap 是否齐全**、备案号 |
| `deploy\pack.js` | 打包成 1 个 zip（22 张网页 + `robots.txt` + `sitemap.xml`），并生成一份清单（含每个文件的大小和指纹） |
| `deploy\static-preview.js` | 纯静态预览用的小服务器（规则和服务器上一致） |
| `deploy\nginx-site.conf` | 服务器配置参考（**本机没实测过**，宝塔用户优先用面板） |
| `deploy\dist\` | 打包出来的 zip 和清单都放这里；**保留最近几个**，就是你的回退用"上一版" |

## 七、为什么选"A 静态上线"（留给以后的你）

- 服务器上**没有会跑起来的程序**，也就没有"程序崩了没人知道"这回事；
- **不用装 Node**，所以服务器是老系统（CentOS 7）也没关系，不用重装；
- 出问题的地方全在你自己电脑上（采集、生成网页），**出错时黑窗口当场红字报错**，你一眼看得见；
- 代价只有一个：**你电脑不开机、不上网，网站就不会更新**（网页不会坏，只是旧）。
